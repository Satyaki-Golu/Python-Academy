# Python Academy — Summary

A lightweight, mobile-first interactive learning app built using **Streamlit** across two files: `app.py` and `curriculum.py`.

---

## Key Features
- **In-Browser Execution:** Run demos and test challenge answers directly.
- **Mobile-Ready:** One-handed dropdown selectors and touch-sized buttons.
- **Progress Tracking:** Saves completed lessons in session state.

---

## Course Modules
1. **Setting Up Environment:** Python & PyCharm installation (Mac, Windows, Linux), PATH check, and PyCharm configuration (white theme, widescreen layout, fonts 14/15).
2. **Fundamentals:** `print()`, variables, typecasting, f-strings, `if-elif-else`, `match-case`, loops (`for`, `while`), and loop control statements (`break`, `continue`, `pass`).
3. **Advanced Datatypes:** Lists, Tuples, Sets, and Dictionaries with built-in functions and methods.
4. **Functions:** Function declaration, `*args`, `**kwargs`, and decorators.
5. **Object-Oriented Programming (OOP):** Classes, instances, `__init__`, inheritance, encapsulation, and polymorphism.

---
